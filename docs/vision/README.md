**Es lo que piensa hoy, y puede cambiar** (Sergio Urcullo, 3-nov). Cada archivo dice de qué versión es y muestra lo vigente. Cuando él cambia algo, se pone al día el archivo y se suma una entrada al final del [historial](historial.md): fecha, qué se decidió, qué cambió y por qué. Las entradas viejas del historial no se borran ni se editan, para que quede cómo fue cambiando su forma de pensar.
