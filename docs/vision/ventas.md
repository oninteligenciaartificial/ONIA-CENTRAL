# Punto 3: ventas

Cerrado por Sergio Urcullo el 3-nov-2026, en el chat del proyecto Onia. El embudo exacto del camino A sigue abierto (ver "Borrador del embudo").

## Nada de freelance

Todo pasa por ONIA, con ingreso que se repite cada mes. Por qué, en palabras de Sergio Urcullo: un trabajo freelance trae un cliente pidiendo cambios a cada rato; con ONIA se le hace el sistema, después se le cobra una página web hecha con ONIA, y sigue pagando el sistema y cada función nueva que se le suma.

## Los dos caminos

- **Camino A, volumen y caja rápida: es el foco de ahora.** Contenido → mensaje directo → clase gratis → taller de Bs 50 → comunidad paga.
- **Camino B, empresas: cuando el core de ONIA Platform esté listo** ([punto 2](onia-platform.md)). Diagnóstico de 20 minutos → auditoría → ONIA → suscripción. El primer contacto es una empresa familiar de Sergio Urcullo. Él prefiere tener el core listo antes de salir a ofrecer.

Sergio Urcullo puede hacer llamadas; lo que lo frena es el tiempo ([contexto](contexto-sergio.md)).

## Lo central: comunidad y marca personal

La comunidad y la marca personal son el activo más importante. La idea es armar alrededor de ONIA un grupo de gente que confía y vuelve a comprar, como hace Iman Gadzhi: muestra valor y la gente le compra una cosa tras otra ([ficha](../../marca-personal/referentes/iman-gadzhi.md)).

ONIA Platform es una startup y hay que pensarla como empresa, pero un SaaS se puede reemplazar. La marca personal, no: es una persona que demuestra valor.

**Idea a futuro:** que la comunidad también sea presencial, con encuentros en persona. Anotada, sin fecha.
