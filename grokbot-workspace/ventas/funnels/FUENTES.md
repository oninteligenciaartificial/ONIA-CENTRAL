# Fuentes: investigación de funnels, webinars y lanzamientos (OnIA, 1/11/2026)

Cómo leer esta lista:
- **[F#]** es el código que usan `MANUAL-FUNNELS.md` y `APLICADO-ONIA.md`.
- **Tipo:** *Libro* (fuente original del marco) · *Primaria* (datos propios de quien publica) · *Vendedor* (empresa que vende la herramienta: sirve de guía, pero tiene interés) · *Secundaria* (resumen de terceros) · *Interna* (archivo de OnIA).
- **Verificada:** "sí" = la página se abrió y se leyó el dato el 1/11/2026. "no" = solo se vio en un buscador. Esas fuentes hay que abrirlas antes de citarlas en público.
- Las URLs que dieron error 404 están al final, para que nadie las use.
